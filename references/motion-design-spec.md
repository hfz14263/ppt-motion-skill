# 动效设计规范（Motion Design Spec）

本文件是 `ppt-office-motion` 的**设计层提示词**：回答"这份 deck 该怎么动"，而不是"怎么把动画写进 XML"。
语法、命令、注入机制见 `SKILL.md`；效果全表见 `references/mso-primitives.md`。

分工原则：**静态版面质量属上游**（内容结构、网格、配色、字体、密度）。本规范只管"动"，
且只允许在**不改变版面几何**的前提下动。所以任何一条动效建议，都必须能在"全部动画被删除"后
依然是一份成立的静态稿。

---

## 0. 动效闸门（先判断该不该动）

**必须先给出动效意图，再挑效果。** 没有意图的动画就是噪声。

| 场景 | 是否加动效 | 理由 |
| --- | --- | --- |
| 现场演讲 / 路演 / 答辩 / 发布会 | **加** | 演讲者控制节奏，动效服务"分段揭示" |
| 培训课件、逐步推导、流程图讲解 | **加（克制）** | 帮助建立因果与顺序认知 |
| 发送给人自己看的阅读稿 | **不加** | 读者自己控制进度，动效只会碍事 |
| 打印 / PDF 交付 / 存档 | **不加** | 导出后动效归零，白做 |
| 数据密集型咨询页（多图多表） | **不加或极少** | 密度已高，再加动效会打架 |
| 封面 / 章节页 / 金句页 | **加** | 情绪与节奏节点，收益最高 |

一句话规则：**"这份 PPT 会不会有人在旁边讲？"** 会 → 加；不会 → 不加。

---

## 1. 五条原则

1. **动效引导注意力，不表演**。每处动画都要能回答："它想让观众先看哪里？"
2. **一页一个视觉主角**。同一时刻只允许一个元素在"抢眼"，其余静止或微动。
3. **首屏不空**。`trigger: with` 只用于背景层（底图、色块、容器），主体内容一律在观众注意力就位后才出现。
4. **宁少勿多**。每页 2–5 个动效组是舒适区；超过 6 组观众会开始等动画而不是听你讲。
5. **可退**。删掉全部动画后，静态版面必须依然完整、可读、可打印。

---

## 2. 节奏与时长阶梯

时长是动效质感的第一来源。**同一份 deck 内应复用这套阶梯**，不要逐页临时拍脑袋。

| 层级 | 时长 | 用途 | 建议效果 |
| --- | --- | --- | --- |
| T0 微 | 0.20–0.35s | 强调、状态切换、图标反馈 | `flash` `boldFlash` `changeFillColor` |
| T1 标准 | 0.40–0.80s | 绝大多数入场 | `fade` `wipe` `fly` `zoom` `growTurn` |
| T2 着重 | 0.90–1.50s | 关键结论、主视觉进场上台 | `zoom` `growTurn` `split` + 缓动 |
| T3 路径 | 1.20–3.00s | 空间关系、流程推进、循环漂浮 | `pathSineWave` `pathRight` `pathArcUp` |

**缓动**：`smooth: 0.4–0.6` 只给 T2/T3。T1 用默认线性即可，写缓动反而显得拖沓。
**间隔**：同一页连续 `after` 的动画，`delay` 给 0.10–0.30s；低于 0.10s 会被感知为"同时"，
高于 0.40s 会让观众等。
**循环**：`repeat` 仅用于**装饰性**元素（漂浮的光晕、旋转的环），且 `repeat ≤ 3` 或配合
`autoReverse: true`。正文、数据、结论**永不循环**。

## 3. 效果 → 语义映射

同一个效果在不同语境含义不同。**按下表选用，不要按"哪个好看"选。**

| 语义 | 首选效果 | 备选 | 禁用 |
| --- | --- | --- | --- |
| 出现 / 就位（中性） | `fade` | `appear` `zoom` | — |
| 强调某事重要 | `zoom` | `growTurn` | `spin`（易显廉价） |
| 方向性进场（左→右阅读流） | `fly` + 方向 | `wipe` `push` | — |
| 数据生长 / 累积 | `stretch` `wipe` | `growTurn` | `spin` `bounce` |
| 空间位移 / 流程推进 | `pathRight` `pathLeft` `pathArcUp` | `pathSineWave` | 自定义路径（除非确有必要） |
| 持续状态（运行中） | `pathSineWave` + `autoReverse` | `spin`（环形元素） | `repeat` 于文字 |
| 揭示 / 展开 | `split` `unfold` | `wipe` | `blinds` `checkerboard`（廉价） |
| 退场 | `fade`（快，T0–T1） | `zoom` 缩小 | 华丽退场 |

**默认三件套**：`fade` / `fly` / `zoom`。它们在任何 PowerPoint 版本上表现一致、观感干净、
不抢内容。**先考虑这三个能不能解决，再考虑别的。**

**慎用清单**（默认不用，除非有明确理由）：`bounce` `boomerang` `pinwheel` `buzzsaw`
`checkerboard` `blinds` `randomBars` `swivel` `spinner` —— 它们在正式场合容易显得业余。

## 4. 页型编排剧本

按页型套用。每行给出**顺序**与**触发方式**，具体元素名以你的 deck 为准。

### 封面
```
1. with : 背景层（底图 / 渐变块 / 光晕）fade 1.0–1.5s
2. after: 主标题 fly 或 zoom 0.6–0.8s
3. after: 副标题 / 日期 fade 0.4–0.5s（delay 0.15）
4. after: 品牌标记 / 装饰线 wipe 0.4s
```
气质取向：**慢一点、稳一点**。封面值得用 T2。

### 章节 / 过渡页
```
1. with : 色带 / 大图 fade 0.8s
2. after: 章节序号 zoom 0.5s
3. with : 章节标题 fade 0.5s
```
只动 2–3 处。过渡页是呼吸点，别堆东西。

### 要点正文页
```
1. with : 容器 / 面板 fade 0.8s
2. after: 各要点依次 wipe 或 fade，每组 delay 0.15–0.25s（逐条建立节奏）
```
用**同一效果、同一时长**贯穿所有要点 —— 一致性比变化更重要。要区分主次，用字号和颜色，
不要用不同动画。

### 数据 / 图表页
```
1. after: 标题 fly 0.6s
2. after: 坐标轴 / 网格 fade 0.4s
3. after: 数据系列逐个 stretch 或 wipe，delay 0.15–0.30s（体现累积）
4. after: 关键数值标注 zoom 0.4s（点睛）
```
**图表动画只强调一个结论**。如果每个柱子都在动，观众记不住任何东西。
**最稳妥的做法：图表整块 `fade`，只让关键那一个数据点用 `zoom` 强调。**

### 对比 / 并列页
```
1. with : 分栏容器 fade 0.6s
2. after: 左栏整体 fade 0.5s
3. after: 右栏整体 fade 0.5s（同样时长、同样效果 = 体现并列对称）
```
对称结构必须用**对称动效**。左栏 fly、右栏 zoom 会暗示"两者不平等"。

### 流程 / 时间轴页
```
1. after: 标题 fade 0.5s
2. after: 主路径线 wipe 0.8–1.2s（先建立路径）
3. after: 各节点依次 zoom 0.4s，delay 0.2s（沿路径推进）
4. after: 当前节点额外用强调效果区分（可选）
```
动效方向**必须与阅读方向一致**。

### 金句 / 强调页
```
1. with : 背景 fade 0.8s
2. after: 金句整句 fade 或 zoom 0.8–1.2s（慢，让观众读完）
```
不要逐字或逐行拆 —— 金句的力量在于整体冲击。

### 收尾页
```
1. after: 核心结论 zoom 0.6s
2. after: 行动项 / 联系方式 fade 0.5s
```
对称呼应封面，但更快、更干脆。

## 5. 页面切换（与元素动画是两回事）

**默认：全片统一一种切换。** 切换风格是 deck 的"语气"，每页换一种会显得散。

| 场景 | 切换 | 时长 |
| --- | --- | --- |
| 通用 / 商务 / 学术 | `fade` | 0.6–0.8s |
| 章节推进感 | `push` | 0.5–0.7s |
| 横向对比 / 并列 | `wipe` | 0.5–0.7s |
| 强调封面、收尾 | `cover` 或 `zoom` | 0.8–1.0s |
| 打印 / 阅读稿 | `none` | — |

**切换顺序建议**：封面进 chapter 用略强的，普通正文页统一用 `fade`，章节页换 `push`。
即"切换也承担章节节奏"，但不要每页都不同。

---

## 6. 密度上限（硬约束）

| 项 | 上限 |
| --- | --- |
| 每页动效组 | **5**（超出请合并或删减） |
| 每页不同**效果种类** | **3** |
| 每页 `repeat` 循环元素 | **1** |
| 单页动画总时长（含 delay） | **≤ 12s** |
| 全片切换种类 | **≤ 3** |

超限时优先删：装饰性循环 > 次要元素的入场 > 章节序号动效。

---

## 7. 可访问性与稳健性

- **不做纯靠动效传递信息的设计**。若某结论只能通过"动画揭示"才能理解，静态版就是失败的。
- **避免高频闪烁**（`flash`/`flicker` 类）用于大面积元素；小图标反馈可以。
- **导出的静态图 / PDF 中，带入场动画的元素会处于隐藏态**。要交付截图或 PDF，
  必须先用 `motion.py preview` 生成去动画副本再导出（见 `references/com-pitfalls.md` §5）。
- **跨版本一致性**：`fade` `fly` `zoom` `wipe` `stretch` 在 PowerPoint 2016→365 表现稳定；
  复杂路径与 `pinwheel` 之类在某些版本或 WPS/Keynote 上会降级。**要跨平台交付就只用默认三件套。**

---

## 8. 交付前自检清单

- [ ] 每处动画都能说出"它想让观众看哪里"
- [ ] 全部动画删除后，静态版面依然完整可读
- [ ] 每页 ≤ 5 组、≤ 3 种效果、总时长 ≤ 12s
- [ ] 同一份 deck 复用了统一的时长阶梯（没有"这页 0.3s、那页 1.8s"的随意感）
- [ ] 对称结构用了对称动效
- [ ] 图表页只强调一个结论，不是全部元素都在动
- [ ] 循环元素只出现在装饰件上，且 ≤ 1 个/页
- [ ] 切换统一（≤ 3 种），阅读稿用 `none`
- [ ] 流程/时间轴的动效方向与阅读方向一致
- [ ] 阅读稿、打印稿、PDF 交付版已确认**不加**动效，或已生成去动画副本

## 9. 与上游设计系统的配合

静态版面设计交给上游，本规范不重复。可选的上游设计资产：

- **dsh-ppt-studio**：内置 4 套自研主题 + 6 张母版 + 声明制门禁（`SKILL.md` §6 的对接契约）
- **open-kimi-ppt-skill**：44 套命名设计系统（`consulting/` `finance/` `work/` `promotion/`
  `academic/`），每套含 `design.md`，规定了色板、字体、布局骨架、图表语言、禁止项与页型版式。
  另有 `slides_categories/` 按 7 类场景（分析决策 / 商业提案 / 管理汇报 / 学术研究 /
  教育培训 / 技术工程 / 品牌创意）给出版面基线，以及 `shapes.md`、`fonts.md`。

接入方式：让上游产出静态 deck（含 `elementId`），再按本规范写 motion spec 注入。
**本规范不假设任何特定上游** —— 只要 deck 有稳定的形状名/id 即可。
