# 交付复核清单

这份清单有两重用途：

1. **避免"判据骗人"** —— 本项目已经发生过三次，每次都是**自动化检查给了错误结论**
2. **评价美感** —— 机器判不了好不好看，但可以把"该看什么"结构化，让人（或视觉模型）按条目过

核心原则：**任何单一判据都可能骗人。结论强度 = 判据数量 × 判据之间的独立性。**
机器判"没有 / 没变 / 不存在"时，**必须**再找一个**正向**判据佐证。

---

## 0. 判据可信度分级（先看这张表）

| 判据 | 能证明什么 | **已知失效场景** |
| --- | --- | --- |
| `lxml` 解析通过 | XML 合法 | **不能**证明 PowerPoint 肯打开；早期注入曾通过 lxml 但 PowerPoint 报 `E_FAIL` |
| `geometry_fingerprint` 相同 | 形状的 tag/id/name/xfrm 未变 | **不能**证"该动的都动了"；漏形状它一样报 UNCHANGED |
| XML 字符串里有某元素 | 写进去了 | **不能**证被采纳。`scene3d` 插错位置时 XML 在、PowerPoint 读回 `PresetCamera=-2` |
| **PowerPoint 对象模型读回** | PowerPoint **采纳了** | **对 p159 扩展无效**：morph 在对象模型里查不到，但确实生效（`EntryEffect=0xF72`） |
| `Slide.Export` 渲染 | 静态态外观 | **OOXML 效果渲染不全**（阴影/3D 可能不体现）；**动画显示起始态**（入场=隐藏，动作路径=起点） |
| `motion.py player` | 时序与分层 | 是**重放**不是真渲染，字体/换行可能与 PowerPoint 不同 |
| 视觉审阅（vision 工具） | "看起来对不对" | **会误报**：实测把"有人物"判成"没有"，也把"梯形"判成"正方形" |
| 人眼 | 最终裁决 | —— |

**读表要点**：越靠上的判据越"便宜"、越弱；靠下的越贵、越强。**不要用上层的结论去替代下层的验证。**

## 1. 结构正确性（全部机器可判）

- [ ] `motion.py apply --assert-geometry` 输出 **`geometry: UNCHANGED`**
- [ ] `verify_motion.py --source <原稿>` 输出 **OK**（well-formed / spid 引用有效 / cTn id 唯一 / 几何一致）
- [ ] `motion.py check` 覆盖率无缺口（**没有"零效果"的形状**）
- [ ] `motion.ps1 -Strict` 往返普查无 `LOSS`（PowerPoint 保存后效果没被吃掉）
- [ ] **所有 `target` 的 id 来自运行时实测**，不是手写（deck 改版式 id 会全体重排）
- [ ] 切换元素在 `<p:timing>` **之前**（`CT_Slide` 是 sequence，位置错了保存后静默消失）
- [ ] 每个形状最多一个效果（同形状"入场+强调"会被 PowerPoint 丢掉）
- [ ] 媒体真的嵌入：`ppt/media/` 下有文件，`.rels` 有 video/audio 关系
- [ ] `[Content_Types].xml` 有对应扩展名声明

## 2. 素材卫生（人看 / 视觉）

> 这一节的由来：`material/template1` 的旋转图层是一张**全屏截图**，把 PowerPoint
> 自己的界面也截进去了（2560×1440，69% 近白像素）。**这是最典型的素材事故。**

- [ ] **没有工具界面 / 截图残留 / 边框条**（菜单、工具栏、窗口标题、滚动条）
- [ ] 没有水印、logo 占位符、保密戳、作者署名残留
- [ ] 没有占位符文字（`Lorem ipsum`、`Click to edit`、`TODO`）
- [ ] 图片**没有被非等比拉伸**（对比原图宽高比）
- [ ] 没有明显压缩噪点、锯齿、色带
- [ ] **抠图边缘干净**：无背景残留、无硬边毛刺、无明显色边
- [ ] 素材分辨率足够（放大到最终显示尺寸不糊）
- [ ] 透明素材的边缘**在深色和浅色背景上都检查过**（半透明黑边常在浅底才暴露）

## 3. 版面美感（人看 / 视觉）

> 具体量化标准见 `references/design-system/*.md`（每套都带**禁止项**）。
> 下面是跨风格通用的判断项。

**层级与信息组织**
- [ ] 每页有**明确的视觉主角**（第一眼看哪里是确定的）
- [ ] 层级靠**字号 / 留白 / 细线 / 字重**建立
- [ ] ⚠️ **不靠卡片堆叠**（圆角矩形、色块分组、色带卡片）——这是最强的 AI 味信号
- [ ] ⚠️ **不做等分构图**（N 个一模一样的格子、四宫格、等宽三栏无主次）
- [ ] 标题是**结论句**，不是名词短语（"成本下降 23%" 优于 "成本分析"）
- [ ] 正文有**可读行长**（中文约 20–35 字/行），不是满屏长行

**排版与栅格**
- [ ] 元素对齐到统一栅格（左对齐元素共享同一 x）
- [ ] 页边距**跨页一致**
- [ ] 留白分布均匀；**没有"实心空白块"**，也没有挤满
- [ ] 同类元素间距一致（不是手放的位置）

**色彩与对比**
- [ ] 一页主导色 **≤2**，强调色**只用于需要强调的地方**
- [ ] 正文与背景对比度足够（浅底深字 / 深底浅字）
- [ ] ⚠️ **没有彩虹配色**（红紫黄绿同时出现在一页）
- [ ] ⚠️ 没有蓝紫渐变、霓虹色、玻璃拟态、发光边框、重阴影 3D 图（除非风格明确要求）
- [ ] 图表配色与页面主题一致，不是默认色板

**跨页一致性**
- [ ] 字体族与字号阶梯**全篇一致**
- [ ] 配色**全篇一致**（同一含义用同一颜色）
- [ ] 页码、来源、页脚位置**跨页一致**
- [ ] 数字**单位统一**（同一指标不要一页 %、一页 个百分点）

## 4. 动效美感（人看 / 视觉）

> 量化标准见 `references/motion-design-spec.md`。
> **§6 的机械上限已做成命令**：`python scripts/design_audit.py --pptx out.pptx --spec m.yaml`
> —— 它输出 FAIL（硬上限）/ ADVISE（启发式，可能正是你要的）/ HUMAN（判不了，只能人眼）
> 三类，并**明说通过 ≠ 复核完成**。

- [ ] **每处动画都能说出"它想把注意力引到哪里"**——说不出就是装饰，删掉
- [ ] **删掉全部动画后，静态版面依然成立**（这条是动效的底线）
- [ ] 每页动效组 **≤5**、不同效果种类 **≤3**、含 delay 总时长 **≤12s**
- [ ] **首屏不空**：`with` 只给背景层，主体内容等注意力就位后再出现
- [ ] 一页同一时刻只有**一个元素在抢眼**
- [ ] **对称结构用对称动效**（左栏 fly 右栏 zoom 会暗示不平等）
- [ ] **图表页只强调一个结论**（每根柱子都在动 = 观众什么都记不住）
- [ ] 循环/往复只用于装饰件，**每页 ≤1**，正文数据结论**不循环**
- [ ] 时长落在同一阶梯内（T0 0.2–0.35 / T1 0.4–0.8 / T2 0.9–1.5 / T3 1.2–3.0 s）
- [ ] `delay` 在 0.10–0.30s（低于 0.10 被感知为同时，高于 0.40 让观众等）
- [ ] 全篇切换种类 **≤3**，且与章节节奏一致
- [ ] 慎用清单未出现（`bounce` `pinwheel` `blinds` `checkerboard` `boomerang`…）
- [ ] 方向性擦除的**方向与阅读方向一致**（且**人眼确认过**——结构闸查不出方向错误）
- [ ] **阅读稿 / 打印稿 / PDF 交付版不加动画**

## 5. 交叉验证规则（专治"判据骗人"）

1. **任何"通过"结论至少两个独立判据。**
   "几何没变" + "结构合法" 不是两个独立判据（都是同一份 XML 推出来的）；
   要加 PowerPoint 真开一次。

2. **机器判"没有 / 没变 / 不存在"时，必须找一个正向判据。**
   例：判"两页完全相同"之前，先证明你的解析器**看得见**那个差异——
   把已知有差异的两页喂进去，看它是否报不同。

3. **涉及分组 / 嵌套 / 扩展命名空间时，必须与对象模型交叉核对。**
   本项目第一次误判（说 template2 不产生补间）就是正则没处理 `<p:grpSp>`，
   读到组变换而不是子形状的 `<a:off>`。**症状是"自信地给出错误答案"。**

4. **视觉审阅与机器判据冲突时，以人眼为准，并把冲突记下来。**
   模板匹配曾给原件打 0.401 的低分（看着像"没人"），视觉复核推翻了它。

5. **改完 OOXML 必须过 PowerPoint 真开一次。** 不是可选步骤。

6. **静态导出 ≠ 动态效果。** 想看"动"必须用 `player` 重放或导 MP4；
   入场动画在导出图里是隐藏的，动作路径显示的是起点。

## 6. 三次真实误判（反面教材，务必先读）

| # | 我说的 | 实际 | 根因 | 教训 |
| --- | --- | --- | --- | --- |
| 1 | "本机不支持 Morph" | **支持**，`EntryEffect=0xF72` | 元素名写成 `p:morph`，正确是 `p159:morph`；查 COM 枚举自然查不到 | **"对象模型没有"≠"不能注入"**。查不到时先怀疑自己写错 |
| 2 | "template2 两页完全相同、不产生补间" | 两页矩形组 left 从 **−180.8** 变到铺开 | 解析脚本**没处理 `<p:grpSp>`**，读到组变换 | 解析器要能看见差异，才能断言"没差异" |
| 3 | "原件的人物不在该位置"（匹配分 0.401） | 人物**就在**那里 | 模板匹配在低对比/缩放差异下不可靠 | **机器判据需要交叉验证** |

三次的共同点：**都是自动化判据给了错误结论，而我没有做交叉验证。**
所以第 5 节的规则不是形式主义，是这三次的产物。
