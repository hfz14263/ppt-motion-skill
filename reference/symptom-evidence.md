# 症状 · 证据与判断

> 「我看到的证据说明不了这件事」这一栏 —— 静态证据证不了运动、单路指标会误判、仪器会选错、规范的值域不等于实测的值域。**关于「怎么才算是证据」的坑。**

## 值越界 / 写错值

越界**不是被忽略，是让文件损坏**。而且规范给的值域不一定合法 —— 本项目实测的上界与规范不同，见下文。

---
## 「我给的证据是静态的，看不到动效」

**你怎么发现**：打开对方给的"效果对照 PPT"，图都不动 —— 只能看到一张张定格画面，
根本没法判断"它到底往哪个方向动"。

**根因**：对方用**抽帧**来证明**运动**。抽帧能证明"某一刻有什么"，
证明不了"怎么动的"。而方向恰恰是要证明的那件事。

**修法**：换成**循环 GIF** 嵌进 pptx（存成 image.gif，PowerPoint 会播）。
但注意 —— 帧数多**不等于**看得见：实测某些效果在某个探测 deck 上
帧间差异只有 0.2，等于静止。要量化"动没动"，低于阈值就换探测素材。

## 「我明明看着是左右开合，你写的是上下」

**你怎么发现**：看效果对照时，某个效果的方向跟文字描述对不上 ——
比如帘子明明是从中间往左右两边拉开，文档却写"自上而下"。

**根因**：判方向的那个指标对该类运动**不敏感**，于是系统就近塞进最像的一族。
这类错误**不会报错**，只会安静地给一个错答案。

**修法**：① 补一个专治这类运动的指标（旋转要按角度扇区分）——
每加一类指标都要问"它看不见什么"；② 用户目视发现的方向错误要**当成一等证据**，
回到原始帧重新量，别用"指标没报警"来反驳。

## 「挂了切换以后，入场动画像慢了半拍」

**你怎么发现**：同一页既设了页面切换（比如 `push`），又给某个元素加了入场动画。
放映时切换先演完，中间空了一小段，动画才慢半拍地开始。
像是动画设置丢了或被压缩了。

**根因**：**切换与页内动画在时间上是串行的，不是并行的。**
页内动画要排队等切换演完才开始。实测延迟 ≈ **切换时长 + 133 ms**：

| 同页的切换 | 动画延迟 |
| --- | --- |
| 无 | +67 ms |
| `fade` 300 ms | +433 ms |
| `push` / `wipe` 800 ms | +933 ms |
| `fade` 1500 ms | +1633 ms |

动画**自己的长度不变**（换什么切换都是 467 ms）—— 切换改的是"起点"，不是"长度"。
两个块在 XML 里**都活着、顺序也对**，所以这既不是"设置丢了"也不是"文件坏了"。

**修法**：① 这是默认行为，不用修 —— 但**填 spec 时要把时长加起来算**：
一页总占用 ≈ `切换时长 + 动画总时长`，想快就别同时给长切换和一串入场动画；
② 想让观众在**翻页过程中**就看到运动，只能用切换本身（整页位移／方向揭示）
或 morph（把运动设计在页间），页内动画拿不到切换那段时间。

## 「动画明明设了，导出视频里却像没跑」

**你怎么发现**：一份只加了页内动画的 deck，用通用"帧间能量"分析，
报出**零个活跃帧** —— 看起来动画根本没生效。

**根因**：**仪器选错了，不是动画没跑。** 中灰圆盘淡入到中灰网格上，
整帧均值变化小于 2/255，落在任何合理阈值之下。
同类坑这是第三次：旋转躲过位移/漂移/径向三类指标（§47），
整页平移躲过变化重心（§48），现在是淡入躲过能量阈值。

**修法**：换一个**能看见这件事**的仪器。本次的做法是让两页的标记用**不同色相**
（第 1 页红、第 2 页蓝），"新页的形状出现了没有"于是变成直接的颜色测量，
一眼就看到 14 帧的线性斜坡。**每加一类"看的方式"都要问它看不见什么。**
